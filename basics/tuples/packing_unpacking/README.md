🧳 Packing & Unpacking Tuples — Exercise
This exercise demonstrates how to unpack nested tuples inside a loop, calculate values from the unpacked data, and repack results into new tuples.

📘 What This Script Does
Iterates through a list of student records

Unpacks each tuple into:

name

age

math, english, science scores

Calculates each student’s average score

Packs the results into a new list of tuples

Prints the final summary
