📄 generate_receipt — Python Learning Project
This folder contains a simple Python function called generate_receipt(), designed to help you practice optional parameters, string formatting, and multi‑step function logic.

The goal of this exercise is to simulate generating a receipt for a customer based on items purchased, tax, and optional discounts.

🎯 Learning Objectives
By completing this exercise, you will strengthen your understanding of:

Defining functions with positional and keyword parameters

Using default values for optional arguments

Building and formatting multi‑line strings

Performing basic calculations (subtotal, tax, total)

Returning clean, readable output
