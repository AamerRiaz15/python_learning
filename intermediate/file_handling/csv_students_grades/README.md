📘 CSV Students Grades — README
Overview
This folder contains a small Python exercise focused on reading, filtering, sorting, and writing CSV data using Python’s built‑in csv module.
It demonstrates practical file‑handling skills and how to work with DictReader and DictWriter.

📁 Files in this directory
students.csv  
The input CSV file containing student names, scores, and pass/fail status.

top_students.py  
A Python script that:

Reads students.csv using csv.DictReader

Filters students who passed

Sorts them by score (highest first)

Writes the results into a new CSV file

Prints a summary to the console

top_students.csv (generated by the script)  
Contains the sorted list of students who passed, including their names and scores.

🧠 What the script does
The script performs the following steps:

Load the CSV file  
Uses DictReader to convert each row into a dictionary based on the header fields.

Filter passing students  
Keeps only rows where "passed" == "yes".

Sort by score  
Converts scores to integers and sorts in descending order.

Write a new CSV file  
Uses DictWriter to create top_students.csv containing only the name and score fields.

Print a summary  
Displays the sorted list of passing students in the terminal.
