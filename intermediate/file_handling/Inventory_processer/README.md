README – Inventory Updater Script
Overview
This Python script reads inventory data from a CSV file, calculates the total value of each item (quantity × price), and writes the updated data to a new CSV file called inventory_updated.csv.

It is designed to help process simple inventory lists and automatically generate a more detailed output file.

Features
Reads inventory data from a CSV file

Converts quantity and price into the correct data types

Calculates total value for each item

Handles blank lines safely

Writes clean, formatted output to a new CSV

Includes basic error handling
